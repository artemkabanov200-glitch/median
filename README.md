## Состав проекта

| Файл | Что это |
|---|---|

## Как открыть

**Вариант 1 (простой, для телефона).** Открыть файл `Сайт_одним_файлом.html` — все стили и картинки
уже внутри него, ничего распаковывать не нужно. Три страницы собраны в один документ, кнопки меню
прокручивают к нужной странице.

**Вариант 2 (полный проект для преподавателя).** Распаковать архив целиком, сохранив структуру папок,
и открыть `index.html` двойным щелчком. Переходы между страницами — через верхнее меню.

> ⚠️ Если открыть один `index.html` **без** папки `images` и файла `style.css`, сайт покажется
> «голым текстом на белом фоне»: браузер не найдёт ни стили, ни картинки. Это не ошибка вёрстки —
> просто страница открыта без своих файлов. Используйте вариант 1 или 2.

## Что выполнено по заданию

- Три страницы, оформленные внешним файлом `style.css` (п. 1, 3, 4).
- Тематика — сайт предприятия: туристическое агентство «Меридиан».
- Исходный «разностилевой» макет приведён к единому деловому стилю: тёмно-синий `#16324F`,
  золотой `#B8894A`, светло-серый фон `#EEF2F5` (п. 1.1).
- В `<title>` — свои данные; рисунок заменён, размер и положение заданы стилями (п. 1.2, 1.4).
- На второй странице таблицы заполнены своими данными (туры, отели, даты, цены), оформление изменено,
  все правки отмечены комментариями `<!-- ... -->` (п. 2.1–2.4).
- Классы `.layer` и `.textstyle0`–`.textstyle4` набраны и изменены под общий стиль (п. 3.2).
- Третья страница `index02.html` заполнена содержимым, изменены шрифты, цвета, выравнивание,
  добавлены рисунки (п. 4).
- Работа протестирована, добавлен вывод с анализом роли CSS (13 предложений) (п. 5, 6).
- Ссылки на внешние источники вынесены в нижний блок на каждой странице.
- Добавлена адаптивность (`@media`) и правила печати (`@media print`).

## Пересборка автономной версии

Если правите `index.html`, `index01.html`, `index02.html` или `style.css`, автономный файл нужно собрать заново:

```bash
python3 tools/build_single.py
```

Скрипт встраивает CSS и сжимает картинки в data-URI и перезаписывает `Сайт_одним_файлом.html`.

## Проверка вёрстки

Страницы протестированы в Chrome и Firefox, а также в режиме эмуляции мобильного экрана
(ширина 390 px): блоки перестраиваются в одну колонку, таблицы туров прокручиваются вбок,
таблица сведений превращается в «карточки», меню прокручивается по горизонтали.
Автономная версия проверена отдельно: все 13 изображений загружаются, «битых» ссылок нет.
